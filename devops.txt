SET 4 – Kubernetes Deployment and Service
Question A: Write a Kubernetes YAML deployment configuration file.
1. What is Deployment?
A Kubernetes Deployment manages application Pods.

A Pod is the smallest deployable unit in Kubernetes. It contains one or more containers.
Step 1: Create a YAML file.
Open CMD:
notepad deployment.yaml

Write:
apiVersion: apps/v1

kind: Deployment

metadata:
  name: my-web-deployment

spec:
  replicas: 2

  selector:
    matchLabels:
      app: my-web

  template:
    metadata:
      labels:
        app: my-web

    spec:
      containers:
      - name: my-web-container
        image: my-web-app:v1
        imagePullPolicy: Never
        ports:
        - containerPort: 80

Save the file.
Explanation
Keyword	Meaning
apiVersion	Kubernetes API version
kind	Type of resource
metadata	Deployment name
replicas	Number of Pods
selector	Identifies Pods
containers	Container information
image	Docker image name
containerPort	Application port
imagePullPolicy	Controls image downloading


Here, imagePullPolicy: Never tells Kubernetes to use the locally available image instead of downloading it.
Step 2: Apply the deployment.
kubectl apply -f deployment.yaml

Step 3: Check deployments.
kubectl get deployments

Step 4: Check Pods.
kubectl get pods

Expected output: Two Pods should be running.

Viva: What is Test-Driven Development (TDD)?
Answer:

Test-Driven Development is a software development approach in which tests are written before writing the actual application code.

TDD follows three main steps:

1. Red: Write a test that initially fails.

2. Green: Write the minimum code required to pass the test.

3. Refactor: Improve the code without changing its functionality.

Example:

Suppose we are developing a registration form.
1. First, write a test to check registration.
2. Write the registration functionality.
3. Run the test.
4. Fix errors until the test passes.
Purpose: TDD improves software quality and helps identify errors early.

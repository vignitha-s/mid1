SET 3: KUBERNETES AND DOCKER

Q3(A) Configure Kubernetes with Docker

First: Docker Desktop → Settings → Kubernetes → Enable Kubernetes → Apply

docker build -t myapp:v1 . kubectl version --client kubectl cluster-info kubectl get nodes apiVersion: apps/v1 kind: Deployment metadata: name: myapp-deployment spec: replicas: 2 selector: matchLabels: app: myapp template: metadata: labels: app: myapp spec: containers: - name: myapp image: myapp:v1 imagePullPolicy: IfNotPresent ports: - containerPort: 80 kubectl apply -f deployment.yaml kubectl get deployments kubectl get pods

Q3(B) Kubernetes setup script

#!/bin/bash echo "Building Docker image" docker build -t myapp:v1 . echo "Checking Docker images" docker images echo "Deploying application" kubectl apply -f deployment.yaml echo "Checking pods" kubectl get pods echo "Setup completed" bash setup.sh

SET 6: SELENIUM WITH JAVASCRIPT

Q6(A) JavaScript test

mkdir seleniumjs cd seleniumjs npm init -y npm install selenium-webdriver const { Builder } = require('selenium-webdriver'); async function test() { let driver = await new Builder() .forBrowser('chrome') .build(); try { await driver.get('https://www.google.com'); let title = await driver.getTitle(); console.log("Page Title:", title); if (title.includes("Google")) { console.log("Test Passed"); } else { console.log("Test Failed"); } } finally { await driver.quit(); } } test(); node test.js

Q6(B) Locate element by ID and click

<!DOCTYPE html> <html> <head> <title>Button Test</title> </head> <body> <h2>Click Button</h2> <button id="submit">Submit</button> <p id="result"></p> <script> document.getElementById("submit").onclick = function() { document.getElementById("result").innerHTML = "Button Clicked Successfully"; }; </script> </body> </html> const { Builder, By } = require('selenium-webdriver'); async function test() { let driver = await new Builder() .forBrowser('chrome') .build(); try { await driver.get('http://localhost:8000/button.html'); let button = await driver.findElement(By.id('submit')); await button.click(); console.log("Button clicked successfully"); } finally { await driver.quit(); } } test(); python -m http.server 8000 node click.js

SET 8: SELENIUM TESTING USING DOCKER

Q8(A) Docker image for Selenium

mkdir selenium-docker cd selenium-docker selenium from selenium import webdriver from selenium.webdriver.common.by import By options = webdriver.ChromeOptions() driver = webdriver.Remote( command_executor="http://selenium:4444", options=options ) try: driver.get("https://www.google.com") print("Page Title:", driver.title) assert "Google" in driver.title print("Test Passed") finally: driver.quit() FROM python:3.12-slim WORKDIR /app COPY requirements.txt . RUN pip install --no-cache-dir -r requirements.txt COPY test.py . CMD ["python", "test.py"] docker build -t selenium-test .

Q8(B) Run tests inside Docker

docker network create selenium-net docker run -d --name selenium --network selenium-net -p 4444:4444 selenium/standalone-chrome docker build -t selenium-test . docker run --rm --network selenium-net selenium-test docker ps docker stop selenium docker rm selenium

SET 9: RUN APPLICATION AND SELENIUM TESTS

Q9(A) Containerized app with Selenium

mkdir finalapp cd finalapp <!DOCTYPE html> <html> <head> <title>Docker Selenium App</title> </head> <body> <h1>Welcome to My Application</h1> <button id="submit">Click Me</button> <p id="message"></p> <script> document.getElementById("submit").onclick = function() { document.getElementById("message").innerHTML = "Test Successful"; }; </script> </body> </html> FROM nginx:latest COPY index.html /usr/share/nginx/html/index.html EXPOSE 80 selenium import time from selenium import webdriver from selenium.webdriver.common.by import By driver = None try: for attempt in range(15): try: driver = webdriver.Remote( command_executor="http://selenium:4444", options=webdriver.ChromeOptions() ) break except Exception: time.sleep(2) if driver is None: raise Exception("Selenium server is not ready") driver.get("http://webapp") print("Page Title:", driver.title) driver.find_element(By.ID, "submit").click() message = driver.find_element(By.ID, "message").text print("Message:", message) assert message == "Test Successful" print("Test Passed") finally: if driver: driver.quit() services: webapp: build: . container_name: webapp ports: - "8080:80" selenium: image: selenium/standalone-chrome container_name: selenium tests: build: context: . dockerfile: Dockerfile.test depends_on: - webapp - selenium FROM python:3.12-slim WORKDIR /app COPY requirements.txt . RUN pip install --no-cache-dir -r requirements.txt COPY test.py . CMD ["python", "test.py"] docker compose up --build

Browser: http://localhost:8080

docker compose down
